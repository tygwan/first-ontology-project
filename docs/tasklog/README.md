1. **언어/내용** (Language / Content): 어떤 언어로 어떤 파일·기능을 작성했는가
2. **문제** (Problem): 작업 중 발생한 문제. 없으면 "없음"으로 명시
3. **분석** (Analysis): 문제의 근본 원인
4. **해결방안** (Solution): 적용한 해결책
5. **결과** (Result): 검증·테스트·커밋 결과
